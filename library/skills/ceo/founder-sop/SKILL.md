# Founder SOP

Use when a recurring task needs others to execute it correctly. Do not use for new ideas.

Write `../shared/01_Projects/<domain>/<project-name>/sop-<task-name>.md`, or in the repo if the task only specifies a repo. Include all sections:

- Task name, version, date, owner.
- Purpose in one sentence.
- Tools and permissions needed.
- Prerequisites before starting.
- Steps. Each step is one action, starts with a verb, and has a visible result.
- Warning before hard-to-reverse steps.
- How to verify completion.
- Common errors, causes, and fixes.
- Recorded assumptions.

Missing a fact: write `not available` in that section. Do not add steps not in the description. Do not write HR or accounting procedures unless the task explicitly requires them.

CEO gate: `## Vietnamese` then `## English`. End with one next step.
