# Launch sprint

Use after a channel exists in `audience-channel.md` and a price exists in `idea-fit.md`.

1. One-sentence message stating the result the buyer receives. Do not name features. `ceo` gate: one Vietnamese sentence and one English sentence.
2. All four assets — missing any: delegate to the right person, do not combine:
   - Brand mark: take from `docs/design/BRAND.md`. Not present: spawn `designer`. Do not create a logo yourself.
   - Getting-started guide: spawn `creator`, skill `customer-guide`. Media skips this if a script already exists.
   - One ad image: spawn `creator`. Creator delegates to `creator-visual`, skill `brand-visual`.
   - One short video: same `creator-visual` from `BRAND.md`. For media: use the existing script, do not render yet.
3. Digital solutions only post after `tester` PASS. Media only posts after a script exists.
4. Stop at WAITING REVIEW before posting or paying. Do not self-post.

Write `../shared/01_Projects/<domain>/<project-name>/launch-sprint.md`. `ceo` gate: two sections `## Vietnamese` and `## English`. End with one next step.
