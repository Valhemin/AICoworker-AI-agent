# Office task

1. Read exactly one task in `../shared/04_Queues/Office/Inbox`.
2. Keep the source file. Work on a copy in `Working`.
3. Save output as `name-v01.ext`, then `name-v02.ext`.
4. Reopen the saved file. Check what the task requires: sheet, column, formula, heading, or slide.
5. Missing business data: write `[NEEDS DATA]`. Do not fabricate.
6. Write `TASK-ID-HANDOFF.md` to `Outbox`.

Do not enable macros, VBA, external content, or add-ins. Do not overwrite the source file.

If a required Office tool is missing, mark Blocked and state clearly what is needed.
