# Learning Experience Design Playbook

## Learning outcome first

Write an observable outcome:

> Given [context], the learner can [behavior] to [criterion].

“Understand” is not observable. Prefer identify, explain, compare, calculate, pronounce, choose, diagnose, perform, or create.

## Instruction sequence

1. Activate relevant prior knowledge.
2. Surface or predict a misconception.
3. Present a clear model or demonstration.
4. Guide one worked example.
5. Prompt retrieval or application.
6. Give feedback.
7. Vary the context to test transfer.
8. Summarize the decision rule, not only the answer.

## Cognitive load

- remove decorative details that compete with the learning target;
- segment complex processes;
- synchronize narration and visuals without duplicating paragraphs on screen;
- pretrain essential vocabulary;
- keep labels near the relevant visual;
- use consistent visual coding;
- provide pause or replay points for dense steps.

## Misconception map

```yaml
misconception:
  incorrect_model:
  why_it_feels_plausible:
  diagnostic_question:
  counterexample_or_demo:
  correct_model:
  transfer_check:
```

A misconception is not fixed by repeating the correct statement more loudly.

## Visual explanation

Choose a visual form based on relationship:

- process → sequence or animation;
- comparison → aligned table or side-by-side;
- hierarchy → nested structure;
- change over time → timeline or graph;
- spatial relation → diagram or map;
- invisible mechanism → analogy plus explicit mapping;
- decision → flowchart or worked cases.

## Story in education

Use story when a character’s goal and mistake embody the concept. Do not add narrative detail that distracts from the learning decision. The learner should be able to state what changed and apply it elsewhere.

## Assessment

- recall checks memory;
- explanation checks mental model;
- application checks transfer;
- error diagnosis checks discrimination;
- creation checks synthesis.

Measure learning separately from entertainment and completion.

## Children and novice audiences

Use concrete language, short instructions, visible examples, safe emotional stakes, and repetition with variation. Avoid overstimulation that prevents attention to the target. Verify reading level and caregiver/teacher context.

## Failure patterns

- objectives added after the script;
- examples all share the same surface features;
- answer appears before retrieval attempt;
- visuals decorate rather than explain;
- speed optimized for retention but not comprehension;
- confidence used as a proxy for learning;
- localization changes examples but not prerequisite knowledge.
