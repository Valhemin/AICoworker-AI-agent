# Platform-Native Creative Playbook

## Viewing context

Design for how the content is encountered:

- feed interruption or active search;
- sound-on or sound-off likelihood;
- screen size and orientation;
- UI overlays and safe zones;
- audience familiarity with the creator;
- expected session behavior;
- package visibility before play;
- link and CTA limitations.

## Vertical short-form

- first frame must orient at small size;
- keep key faces, product, and text away from interface zones;
- captions should support, not duplicate, every spoken word;
- build for thumb-stop and continuation, not only a dramatic title card;
- use duration required by the idea, not the platform maximum;
- create a clean master and platform-specific export.

## Long-form video

- title/thumbnail provide the initial promise;
- opening demonstrates that the click was justified;
- chapter sequence increases value and consequence;
- visual changes follow content needs;
- end screen or next-view bridge continues the audience job.

## Static and carousel

- slide one is a package, not an introduction page;
- each slide advances one idea;
- hierarchy remains legible on mobile;
- sequence creates progression;
- final slide resolves the promise and gives next action.

## Professional and B2B

Use operational specificity, evidence, tradeoffs, and consequences. Avoid generic motivation. Comments from relevant practitioners may be more valuable than broad reach.

## Owned channels

Newsletters, blogs, and communities can carry nuance and direct relationships. Use external platforms for discovery and owned channels for depth, continuity, and conversion where appropriate.

## Spec freshness

Store specs in platform profile files with `last_verified`. At export time, verify current official documentation, because lengths, eligibility, measurements, and ad rules change.
## Platform decision table

| Context | Prioritize | Avoid |
|---|---|---|
| discovery feed | immediate orientation, recognizable value, native framing | long logo pre-roll or context-free cinematic opening |
| search-led video | query satisfaction, proof, chapters, precise package | vague mystery that delays the searched answer |
| paid social | offer/claim clarity, proof, disclosure, measurable variant | changing five variables between tests |
| professional feed | operational specificity, evidence, tradeoffs | generic inspiration and unsupported certainty |
| owned channel | depth, continuity, first-party relationship | copying feed pacing when nuance is the value |

## Adaptation workflow

1. Define the audience session and content job.
2. Load the dated platform profile and verify unstable specifications.
3. Identify package-before-play, first-frame, body, CTA, comment/community, and next-view roles.
4. Decide whether the source should be cropped, re-edited, transcreated, or rebuilt.
5. Produce a clean master plus platform-native versions.
6. Inspect the final asset inside a realistic UI mockup at mobile size.
7. Record platform, market, date, variant, and measurement definition in the experiment log.

## Failure recovery

If retention is weak, separate package mismatch, slow orientation, low proof, and format fatigue before rewriting everything. If a crop destroys composition, redesign the shot or use a dedicated layout rather than automatic center-crop. If localization causes text overload, change hierarchy and edit timing instead of shrinking text.

## Acceptance criteria

The content preserves its core promise while behaving naturally in the named platform context; package, first frame, duration, safe zones, captions, CTA, and measurement are verified for the target market and release date.
