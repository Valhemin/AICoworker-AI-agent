# Web SEO

Call when the slice is a publicly accessible web page, or an article that will live on the site. Skip for APIs, authenticated screens, apps without URLs, and all `developer-work` tasks.

For each indexable URL:

1. One `title` and one meta description that describe what the page does. `ceo` gate: a Vietnamese version and an English version, each with its own URL or its own language-appropriate title.
2. One `h1`. Lower headings do not skip levels.
3. Semantic HTML: `main`, headings, buttons are `button`, links are `a`.
4. Images have descriptive `alt` text. Decorative images have empty `alt`.
5. `canonical` points to the real URL. `og:title` and `og:description` are present.
6. Primary content is in HTML, not only in images.

Do not keyword-stuff. Do not add pages just to capture keywords. Write what was added in the report. End with one next step.
