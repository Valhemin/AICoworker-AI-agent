1. One ad image: correct brand identity, correct colors, correct tagline. `ceo` gate: one version with Vietnamese text and one with English text, same layout.

3. Write the prompt or file to `docs/launch/`. Do not render in bulk. Stop at WAITING REVIEW before paying for a render.

Do not change the brand identity. Do not introduce a new visual direction. End with one next step.
