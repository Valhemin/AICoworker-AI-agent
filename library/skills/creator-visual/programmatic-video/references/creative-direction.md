# Creative direction (read before writing spec.json)

Adapted from open-source skills: iart-ai/motion-design-skills (MIT: motion-art-direction, animation-principles, beat-sync-editing), Liamrjohnston/remotion-motion-graphics-skill (MIT), remotion-dev/skills. Read the originals for depth; this is the working summary.

A spec that only restates the web page is a slide deck. Decide these first:

1. **One message, one viewer, one action.** One sentence each. Everything else is cut.
2. **Hook (0-3s).** Open on the strongest claim or a pattern-break, never a logo card. `hook` scene, <=9 words, end on the payoff word in `**bold**`.
3. **Story arc.** Hook -> problem or promise -> show it working (`ui` / `screenshot` / `footage`) -> proof (`counter`, `features`) -> how to start (`steps`) -> price/offer -> one CTA. Show the product doing the thing before listing features.
4. **Pacing.** A new visual every 3-6s. Vary scene types. Short sentences. Longer holds only for the number or price the viewer must read.
5. **Motion language (pick one personality, keep it):** Energetic = fast, snappy, overshoot; Corporate = clean, little overshoot; Premium = slow, long eases. Entrances ease-out, exits ease-in, 40-80ms stagger, <=2 easing curves. Motion hierarchy: hero moves most, support less, background barely.
6. **Sound.** Voice leads; music under it (ducks automatically); whoosh on cuts, hit on the hook/number/CTA. Music BPM sets the cut grid: frames per beat = 60/BPM*fps.
7. **Visual proof beats claims.** Use real screenshots/recordings of the real product when you have them; the `ui` scene is a clearly labelled illustration only. Never invent users, numbers, testimonials, or logos.
8. **Restraint.** If a motion does not carry meaning, remove it. Captions on, but no caption under the hook text.

Rights/ethics gate (any genre): advertise only what the owner can legally offer. If the product touches third-party content, include a "use only content you have rights to" line, and do not promise "download anything".

Before render, self-review the spec: does second 0-3 stop a scroll? is every number real? is there a next step?
